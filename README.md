как работает алгоритм: 
k = 0 -  Возвращает список с одним пустым сочетанием
k > len(l) - невозможно, вернуть пусто
Для каждого элемента списка:
Фиксируем текущий элемент
Из оставшихся элементов рекурсивно генерируем сочетания размера k-1
Добавляем фиксированный элемент к каждому полученному сочетанию
Ключевой принцип:
Каждое сочетание размера k состоит из:
Текущего элемента + сочетание размера k-1 из оставшихся элементов

Временная сложность:
O(C(n,k) × k) - как и у стандартных реализаций
Где C(n,k) - количество сочетаний

Почему временная сложность O(C(n,k) × k)
1. Количество узлов в дереве рекурсии:
2. Стоимость создания каждого сочетания:
3. Рекурсивные вызовы
