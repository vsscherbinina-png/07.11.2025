Сколько существует перестановок множества из n элементов? 
Количество перестановок множества из n элементов

Ответ: n! (n-факториал)

Формула:
P(n) = n! = n × (n-1) × (n-2) × ... × 3 × 2 × 1
Примеры:
n = 3: 3! = 3 × 2 × 1 = 6 перестановок
n = 4: 4! = 4 × 3 × 2 × 1 = 24 перестановки
n = 5: 5! = 5 × 4 × 3 × 2 × 1 = 120 перестановок
Особые случаи:
n = 0: 0! = 1 перестановка (пустое множество)
n = 1: 1! = 1 перестановка (единственный элемент)
Обоснование:
Для первого элемента есть n вариантов выбора, для второго - (n-1) вариантов, и так далее до последнего элемента, для которого остаётся 1 вариант.
